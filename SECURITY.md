# Security policy

Xenia currently publishes research and a draft specification, not executable software. Security concerns can still arise from unsafe credential-handling recommendations, examples that could cause secret exposure, or future implementation vulnerabilities.

Please report such concerns privately through [GitHub's private vulnerability reporting](https://github.com/dhk/xenia/security/advisories/new). Do not include live credentials, tokens, personal data, or production secrets. Provide the affected document or future component, the risk, reproduction details if applicable, and a safe contact method.

If private vulnerability reporting is unavailable, contact a maintainer privately through their GitHub profile and ask for a secure reporting channel without disclosing sensitive details publicly. Public issues are appropriate only after coordination or for non-sensitive editorial concerns.

No response-time or remediation SLA is promised at this research-stage maturity. Maintainers will acknowledge reports when possible, minimize access to report data, coordinate disclosure, and credit reporters who request it when safe.
